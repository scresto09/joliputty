Welcome to JoliPuTTY

A playful fork of Simon Tatham's PuTTY
by Sylvain Cresto ;-)

JoliPuTTY is a playful fork of PuTTY, the free (MIT-licensed) Windows Telnet and SSH client, which gives PuTTY a modern WinUI 3 look on Windows 11, with tabs, split panes and a redesigned configuration window. This manual documents JoliPuTTY, and PuTTY's companion utilities PSCP, PSFTP, Plink, Pageant and PuTTYgen.

chapter 2 describes what JoliPuTTY does differently from PuTTY. The rest of the manual is PuTTY's own: it still says ‘PuTTY’, and describes PuTTY's configuration dialog box, whose settings JoliPuTTY keeps, although some of them are on different pages (see section 2.5.7).

Like PuTTY's, this manual is about the Windows versions of the tools. JoliPuTTY doesn't change the Unix version of PuTTY.

JoliPuTTY is an independent project, and is not affiliated with the PuTTY project. It is provided as is, without any warranty.
