JoliPuTTY README
================

This is the README file for the JoliPuTTY MSI installer. If you're
reading this, you've probably just run the installer and installed
JoliPuTTY on your system.

JoliPuTTY is a playful fork of PuTTY, the SSH and Telnet client, with
a WinUI 3 look for Windows 11. It is an independent project, and is
not affiliated with the PuTTY project. It is provided as is, without
any warranty.

What should I do next?
----------------------

Run JoliPuTTY from the Start menu. If you chose to put its
installation directory on your PATH, you can also run 'jputty' from a
Command Prompt, with PuTTY's usual command line ('jputty user@host',
'jputty -load "session"', ...).

(Note that a Command Prompt that was already open before you ran the
installer will not have inherited the update of PATH.)

JoliPuTTY uses the same saved sessions as PuTTY, so if you already
use PuTTY, you'll find yours there. Uninstalling JoliPuTTY leaves them
in place.

The first time it runs, JoliPuTTY may say that it needs the Windows
App Runtime, Microsoft's library for WinUI 3 applications, and offer
to take you to Microsoft's page to download it. Install it, and start
JoliPuTTY again.

Where's the manual?
-------------------

On JoliPuTTY's web site: choose Help in the menu of the window's icon
(top left), or "JoliPuTTY Manual" in the Start menu.

What do I do if it doesn't work?
--------------------------------

JoliPuTTY's web site is

    https://github.com/scresto09/joliputty/

To report a problem, see its issues page:

    https://github.com/scresto09/joliputty/issues

Please don't report problems with JoliPuTTY to the PuTTY team: they
have nothing to do with it.
